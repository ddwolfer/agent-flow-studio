## 核心邏輯鏈（5 層推理結構）

Eason 的分析有固定的推理順序，每集幾乎都按此展開：

### 1. 利空本質判斷：人造 vs 結構性
- **人造利空**（川普發起的事件）→ 美國終會縮手 → 短空長多 → 拉回是買點
- **結構性利空**（經濟衰退、AI泡沫破裂）→ 需要真正減碼
- 判斷依據：「美國是主動還是被動？」主動發起 = 人造 = 可收手

### 2. 台股優勢論
- 台灣 = AI 供應鏈 80-90%
- 只要 AI 軍備競賽不停 → 台股就有「金鐘罩」
- 台股位階雖高但有本錢（台積電 EPS 支撐）
- **但此論述在 AI 趨勢反轉時可能失效**（框架目前尚無此情境的數據）

### 3. 籌碼信號判讀
- 外資淨空單 ↓ → 外資不看空了 → 多頭訊號
- 外資淨空單 ↑ → 避險心態 → 但不代表看空（可能只是權重調整）
- 外資現貨賣超 → 挖東牆補西牆 → 避開權值股，轉買中小型
- 融資斷頭 → 籌碼換手完成 → 底部訊號

### 4. 技術面定位
- **季線** = 最重要的多空分界線。季線不破 = 看回不看空
- **月線** = 短期支撐。月線之上偏多操作
- **歸離率** > 15% → 過熱 → 預期拉回降溫
- **N字型態** = 漲→回→再漲，每波高於前高。拉回的N撇 = 買點
- **櫃買指數** = 中小型AI股的溫度計，創25年新高 = 主升段

### 5. 選股策略
- **選股至上**：好的進攻 = 最好的防守
- **買黑不買紅**：出現黑K拉回時進場，不追紅K
- **避開權值股**：外資在賣超的火車頭不要去對撞（鴻海是反面教材）
- **聚焦AI六大族群**（見 eason-sectors.md）

## 風控邏輯

在這 9 支影片中觀察到的風控觀點：
- 「不要超過 50% 空手」→ 至少一半資金要在場內
- 「不用買最低，試貨減便宜就夠」→ 分批進場
- 歸離率過大時建議做空（台指期空單），但快速翻多
- 避開權值股（鴻海等）= 避開外資賣壓
- 美債ETF 持續建議換股（認為美債長期弱勢）

**明顯缺失**：在這段期間他沒有明確建議「全面減碼」或「離場觀望」。需要更多空頭市況的數據才能完善風控框架。

## 歷史類比模式

Eason 常用的歷史類比：
1. **去年對等關稅**（2025年4月）→ 人造股災 → 川普縮手 → V型反轉 → 暴賺
2. **去年台幣之亂**（2025年5月）→ 台幣升值 = 利多不是利空
3. **去年YS進攻單**（2025年7月）→ 不會用暴跌的方式，會卡空
4. **1979年第二次石油危機** → 當時美國被動 ≠ 這次美國主動 → 不能類比
5. **去年11-12月W底** → 拉回季線兩次後噴出 → 這次可能縮小版重演
