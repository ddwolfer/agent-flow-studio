# 逐字稿取得規則（重要：請嚴格遵守）

## 唯一正確做法

取得 Eason 影片逐字稿的**唯一方式**是呼叫 MCP 工具：

```
mcp__yt-dlp__ytdlp_download_transcript(video_url="<影片 URL>")
```

工具回傳結果的 `text` 欄位即為已清理的逐字稿純文字，**直接據此進行分析**，無需任何額外步驟。

## 回傳欄位說明

| 欄位 | 說明 |
|------|------|
| `source` | `"captions"`（字幕）/ `"gemma4:e4b"`（語音辨識）/ `"none"`（無法取得） |
| `text` | 已清理的逐字稿文字（VTT 標記已去除、重複行已合併） |
| `full_chars` | 完整清理後的字元數（截斷前） |
| `truncated` | `true` 表示逐字稿經過精簡（頭尾保留，中段省略） |

## 截斷情況處理

若 `truncated` 為 `true`，`text` 包含：
- **前段**（約 60%）：影片開頭至大盤分析段落
- 中段省略標記：`[...middle elided N chars...]`
- **後段**（約 40%）：個股點評與操作建議段落

請以提供的 head+tail 內容為準進行分析，並在報告中的「資料來源」或「重要限制」段落**明確註記**：「逐字稿因長度限制經過精簡（完整 full_chars 字元），中段約 N 字元省略，分析基於頭尾主要段落。」

## 絕對禁止事項

- **禁止**嘗試讀取任何逐字稿檔案（`.vtt`、`.srt`、`.txt`）
- **禁止**使用 Bash、python 或任何 shell 指令讀取本地檔案
- **禁止**使用 `Write` 或 `Read` 工具存取逐字稿
- **禁止**因為「逐字稿檔案無法讀取」而降低分析信心值——工具結果 `text` 欄位即是全部所需資料

## source 為 "none" 時

若工具回傳 `source: "none"` 或 `text` 為空，則在報告中明確標示「逐字稿不可用，以下分析僅依據影片標題與市場數據，信心值 4/10」，並繼續完成其餘分析步驟。**不要重試、不要嘗試讀檔。**
