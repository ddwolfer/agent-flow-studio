# Generate Report — HTML/PDF 報告生成

Generate professional reports in HTML or PDF format using Markdown as intermediate and Pandoc for conversion.

## Workflow

1. **Gather content**: From conversation or SQLite
2. **Generate charts**: Chart MCP → save SVG/PNG to `reports/assets/`
3. **Create Markdown** with YAML frontmatter:
   ```yaml
   ---
   title: "{topic}"
   date: "{date}"
   author: "Generated by Claude Code"
   lang: zh-TW
   ---
   ```
4. **Convert**:
   - HTML: Use Pandoc MCP → standalone HTML with embedded CSS
   - PDF: Use Pandoc MCP → PDF (requires LaTeX for CJK)
   - Fallback for PDF: HTML → Playwright print-to-PDF
5. **Save**: `/mnt/c/FINANCIAL/reports/{date}_{topic}.{html|pdf}`

## Format Selection Guide

| Format | Best For | Pros | Cons |
|--------|---------|------|------|
| HTML | Interactive viewing, sharing via browser | Responsive, linkable, no special viewer | No print formatting |
| PDF | Printing, formal distribution | Fixed layout, universal | Static, larger file |
| DOCX | Editing, collaboration | Editable | Use /generate-docx instead |
| PPTX | Presentations | Visual | Use /generate-pptx instead |

## Dependencies
- Pandoc (installed via apt)
- For PDF: LaTeX distribution (texlive) or Playwright fallback
