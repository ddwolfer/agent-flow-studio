## Formatting Standards

### Language
- **中英混合**: Analysis text in Traditional Chinese, indicator names and technical terms in English
- Example: "Fed 維持利率不變，但 dot plot 顯示年底前可能降息 2 碼，Core PCE 目前為 2.8%，仍高於 2% 目標"

### Citations
- Every data point must reference its MCP source
- Format: "Source: FRED ({series_id}, {date})" or "Source: Yahoo Finance ({ticker}, {date})"
- Historical claims must reference the specific episode

### Charts
Generate using Chart MCP (AntV). Recommended:
- Time series line chart for key indicators
- Bar chart for cross-country/sector comparison
- Heatmap for regime identification
- Scenario probability bar chart

### Quality Standards (from deep-research-skill)
- 10+ data points cited, 3+ per major claim
- All claims cited with source immediately
- No fabricated data or unsupported assertions
- Prose-first (≥80%), bullet lists sparingly
- Every figure and table has a source attribution
