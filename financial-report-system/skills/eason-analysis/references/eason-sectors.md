# Eason 追蹤族群 + 個股分類

## AI 核心六族群（看多區）

出現率均為 8-9/9，是 Eason 的主力推薦方向。

### 1. 記憶體（9/9）
- **領先指標**：美光(MU)股價，月線不破 = 可低接
- 代表個股：南亞科(2408)、華邦電(2344)、晶豪科(3006)、旺宏
- 操作：跌停板/跌破季線時低接，「別人恐慌我貪婪」

### 2. 散熱（9/9）
- GTC大會直接點名，100%水冷散熱時代
- 代表個股：雙鴻(3324)、奇鋐(6271)、建準
- Eason 稱之為「躺著賺」的族群之一

### 3. 設備股/CoWoS（9/9）
- 台積電資本支出持續上調 → 設備需求確定
- 代表個股：萬潤(6187)、弘碩(紅碩)、辛耘(3583)、星雲(3583)
- 萬潤是他的「紅包標股」，364進場衝到700+

### 4. PCB/ABF/載板（8/9）
- 銅箔基板上游、GPU+TPU需求
- 代表個股：金像電、華通、聯茂、富喬(1815)、台光電、台燿
- 金像電是 PCB 指標股

### 5. CPO 矽光子（8/9）
- GTC大會後 Eason 稱為「躺著賺」的第二族群
- 代表個股：上詮、波若威、華星光(4979)
- 波若威直接要挑戰千金股

### 6. 封測（較低頻）
- 3D封裝、散出型面板級封裝(FOPLP)
- 代表個股：齊邦、日月光、力成

## Eason 避雷區（看空/不推薦）

### 權值股（外資提款標的）
- **鴻海(2317)**：唯一被一致看空的個股（3次提及全部看空）
  - 原因：毛利率不如預期、外資持續賣超、從250跌到195
- **廣達、緯創、緯穎**：老AI伺服器股，「腳麻難逃」
  - 原因：輝達本身股價都在季線以下卡很久

### 航運股
- 萬海、陽明：「有航無事」
- 運價漲但出不了船（中東戰火 → 船不敢進 → 成本上升但需求沒增）

### 美債 ETF
- 持續強烈建議「趕快來換好股」
- 「不降息美債怎麼漲？」
- 「兩年前就叫你不如買0050」

### 傳產/塑化
- 不推薦，「不用買塑化航運股」
