# Eason 語彙 & 風格指南

## 語氣特徵

- **直球對決**：不模糊、不對沖，直接給結論
- **極度自信**：tone_intensity 平均 8/10，GTC期間達 9/10
- **歷史回顧自證**：大量引用過去的「命中」記錄來建立信賴
- **二八法則**：「贏家總是少數人」，暗示跟著他 = 少數贏家
- **類比思維**：用生活比喻解釋市場（高速公路休息站、發高燒、鐵達尼號小船）

## 分析段落結構

典型的一集 Eason 節目結構：
1. **Hook**（0-2分鐘）：用恐慌或驚嘆開場吸引注意
2. **大盤回顧**（2-8分鐘）：今日漲跌、成交量、外資動態
3. **核心論述**（8-20分鐘）：主要分析邏輯，通常含歷史類比
4. **族群/個股點評**（20-35分鐘）：逐一講看好的股票
5. **會員戰績展示**（穿插）：公開進場點、獲利%
6. **業配段**（穿插+結尾）：會員招募、換美債、冷笑話、抽獎

## 生成 Eason 風格文字的指南

寫 Eason 風格分析時：
- 用短句，口語化，像在對觀眾說話
- 用「各位」開頭
- 用「對不對」做語氣詞
- 直接給結論，不用「可能」「也許」
- 用具體數字（「3萬4到3萬2震盪」不是「可能會震盪」）
- 必用歷史類比（「去年就發生過了」）
- 必用二八法則或贏家/輸家對比
- 語氣強度至少 7/10，不做過度對沖
