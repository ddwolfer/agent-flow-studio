# Thinking Frameworks for Content Analysis

Merged from: deep-reading-analyst-skill (SCQA, critical thinking, inversion thinking)

Apply these frameworks when analyzing YouTube financial content to extract deeper insights beyond surface-level summary.

---

## 1. SCQA Framework (McKinsey Structure)

**Purpose**: Quickly structure the host's argument into a logical flow.

| Element | Question | Apply To |
|---------|---------|----------|
| **S** — Situation | What is the current state? | Background context the host describes |
| **C** — Complication | What changed or went wrong? | The event/data that prompted this video |
| **Q** — Question | What needs to be answered? | The core question the host is addressing |
| **A** — Answer | What is the proposed solution/view? | The host's thesis and recommendations |

**Example applied to a 游庭皓 video**:
- S: "美國通膨已從 9% 降至 3%"
- C: "但最新 CPI 反彈至 3.5%，超出預期"
- Q: "Fed 會不會延後降息？對台股有何影響？"
- A: "核心 PCE 仍在下降軌道，Fed 年底仍可能降 1 碼，台股短線震盪但中期不悲觀"

## 2. 5W2H Completeness Check

**Purpose**: Ensure the analysis covers all angles of the topic discussed.

| Question | Apply To | Example |
|----------|---------|---------|
| **What** | What event/data is being discussed? | "Fed 維持利率不變" |
| **Why** | Why did it happen? What caused it? | "因為通膨仍高於目標" |
| **Who** | Who is affected? Who decides? | "Fed 委員、台灣央行、出口企業" |
| **When** | When will impact be felt? Timeline? | "下次 FOMC 在 6 週後" |
| **Where** | Which markets/regions affected? | "美股、台股、新興市場" |
| **How** | How does the transmission mechanism work? | "利率不變→美元持穩→台幣壓力小" |
| **How much** | Magnitude of impact? | "預估影響台股 200-500 點" |

**Use**: Quick completeness check — if the host's analysis covers all 7 questions, it's comprehensive. Missing questions = gaps to flag.

## 3. Critical Thinking Framework

**Purpose**: Evaluate the strength of the host's arguments.

### Argument Structure Analysis
1. **Claim**: What is the host asserting?
2. **Evidence**: What data/facts support it?
3. **Reasoning**: How does the evidence lead to the claim?
4. **Assumptions**: What unstated assumptions are required?
5. **Counter-evidence**: What evidence contradicts the claim?

### Logical Fallacy Check

| Fallacy | Description | Financial Example |
|---------|-------------|------------------|
| Cherry-picking | Selecting only supporting data | "過去 3 次降息台股都漲" (忽略其他次) |
| Post hoc | X happened then Y, so X caused Y | "外資買超後大盤就漲" (可能反過來) |
| Appeal to authority | "巴菲特說..." without context | 巴菲特的情境可能不同 |
| Slippery slope | One event leads to extreme outcome | "升息一碼就會引發衰退" |
| False dichotomy | Only two options presented | "要嘛軟著陸要嘛硬著陸" (可能不著陸) |
| Anchoring | Stuck on a previous number | 一直用舊目標價當參考 |
| Survivorship bias | Only citing successful predictions | 只提對過的預測 |
| Composition fallacy | Part is true → whole is true | "台積電好所以台股好" |

### Evidence Strength Rating

| Rating | Criteria |
|--------|---------|
| Strong | Specific data with source, recent, multiple supporting points |
| Moderate | Some data but incomplete, or single source |
| Weak | Opinion, anecdotal, or outdated data |
| Missing | Claim made without any supporting evidence |

## 3. Inversion Thinking (Charlie Munger)

**Purpose**: Identify risks by thinking about what could go wrong.

Instead of asking "Why will this work?", ask:

### Inversion Questions for Financial Content
1. **What would make this thesis WRONG?**
   - What data would invalidate the host's prediction?
   - What event would reverse the expected outcome?

2. **What is the host NOT considering?**
   - Missing risk factors
   - Alternative explanations for the same data
   - Scenarios outside the host's mental model

3. **What would a smart contrarian argue?**
   - The strongest bear case if the host is bullish
   - The strongest bull case if the host is bearish

4. **What are the second-order effects?**
   - If the host's prediction is correct, what else would happen?
   - Are those second-order effects consistent with reality?

### Apply to Each Market View
For every bullish/bearish stance the host takes:
- **If bullish**: What's the top risk the host is underweighting?
- **If bearish**: What positive catalyst is the host ignoring?
- **Time risk**: What if the timing is wrong even if direction is right?

## 4. Applying Frameworks to Financial YouTube

### Quick Analysis (每日追蹤)
- SCQA only — structure the video's argument in 4 sentences

### Standard Analysis (重要影片)
- SCQA + Critical Thinking — structure + evaluate argument quality

### Deep Analysis (關鍵決策時刻)
- All three frameworks + cross-reference with live data
- Generate specific "what would prove this wrong" checklist

### Framework Selection by Channel

| Channel | Best Frameworks | Why |
|---------|----------------|-----|
| 游庭皓 | SCQA + Critical Thinking | 總經論述需要檢驗邏輯鏈和數據品質 |
| 張貽程 | Critical Thinking + Inversion | 籌碼分析需要檢驗因果關係和反面風險 |
| Both combined | All three + cross-channel comparison | 綜合分析需要完整框架 |
