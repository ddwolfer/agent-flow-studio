# Eason 台股實戰簡報任務

你的任務：為 ${WORKFLOW_NAME}（${DATE}）產出一份**Eason 台股實戰每日簡報** HTML，寫到 `${OUTPUT_PATH}`。

來源宣告（JSON）：
```
${SOURCES_JSON}
```

前置：你應已依 `digest.md` 把今日 Eason 影片的逐字稿**逐頁讀完**並結構化保留在工作記憶中。若還沒做，先回去做。

## 步驟

1. **抓 TWSE 籌碼與大盤**：對下列呼叫 `mcp__twse__*` 取**最近交易日**的觀察事實：
   - `get_market_index_info()` —— 加權指數、櫃買指數、寶島指數收盤與漲跌
   - `get_daily_market_trading_info()` —— 大盤成交量、漲跌家數
   - `get_margin_trading_info()` —— 融資融券餘額與增減
   - `get_foreign_investment_by_industry()` —— 外資對各產業的買賣超分佈
   - 若 Eason 在逐字稿中明確點到的個股有代號，逐檔呼叫 `get_stock_daily_trading(stock_no=<代號>)` 取近期 K 棒 / 三大法人買賣超
   - 任一項回傳空 / 失敗 → 在報告中標註「該項今日不可用」，繼續其他項。

2. **抓 Yahoo TW + US 指標**：先 `mcp__yahoo-finance__get_stock_info(symbol=<ticker>)`，必要時 `get_historical_stock_prices(symbol=<ticker>, start_date=<約 ${DATE} 往前 60 天>, end_date=${DATE})` 取歷史以算季線、月線、乖離率、N 字位階：
   - 台股：`^TWII`（加權）、`0050.TW`、`00878.TW`（觀察 ETF 動向）
   - 台積電 ADR：`TSM`
   - 美股關鍵：`NVDA`、`MU`（美光）、`^SOX`（費半，若 Yahoo 可查；不可查就 `SOXX`）、`^GSPC`、`^IXIC`、`^VIX`、`DX-Y.NYB`、`^TNX`
   - Eason 點名個股若有美股對應或 ADR，補抓

3. **（可選）抓 FRED 政策利率參考**：呼叫 `mcp__fred__fred_get_series(series_id="DFF", ...)` 取美國有效聯邦資金利率近 1-3 個觀測，用於「外部環境」段落的政策定位（不是主軸；台股主軸是籌碼與技術面）。

4. **綜合分析**：依 framework（5 層籌碼推理）+ voice（Eason 語氣）做整合：
   - **籌碼面**為主軸：外資、投信、融資餘額是否一致
   - **技術面**驗證：季線、月線、乖離率、N 字、櫃買位階
   - **逐字稿**校準：Eason 今日明確說的立場、選股、風險才能寫進報告；他沒講的就不要替他腦補
   - 三方（籌碼、技術、Eason 逐字稿）一致 → 強化訊號；分歧 → 明確列出背離

5. **產出 HTML**：用 `Write` 工具把完整 HTML 寫到 `${OUTPUT_PATH}`。報告標題為「Eason 視角：台股 AI 戰情室 ${DATE}」。HTML **必須**自己內嵌簡潔可讀的 CSS（基本字體、表格邊框、用顏色／emoji 標示看多／看空／中性，但勿過度）。

**HTML 報告必須依序包含以下段落標題（缺一即不合格）**：

- **指標儀表板** —— 表格形式列出當日（或最近交易日）的觀察事實：加權指數收盤＋日變化%、櫃買指數收盤＋日變化%、大盤成交量、外資現貨買賣超、外資期貨淨部位（若可得）、投信買賣超、融資餘額變化、台積電 ADR（TSM）收盤、NVDA 收盤、MU 收盤、費半位階、`^VIX`、`DX-Y.NYB`。**只列觀察事實，不下因果**（不可寫「顯示資金回流 AI」這類腦補因果）。
- **五層邏輯鏈分析** —— 依 framework：1) 利空本質（人造 vs 結構性）2) 台股優勢 / AI 供應鏈 3) 籌碼信號 4) 技術面定位 5) 選股策略。每層先寫「資料／逐字稿實際出現的事實」，再標 Eason 框架對應的解讀。
- **今日語錄** —— 5-10 句 Eason 在今日逐字稿中的**原話逐字引用**（加引號 `「…」`），不可改寫、不可翻譯、不可潤飾。若逐字稿不可用，本段寫「（逐字稿不可用）」。
- **風險提示** —— 包含：(a) Eason 在逐字稿中**實際提到**的風險；(b) 資料面風險（外資連續賣超日數、融資斷頭警戒、台積電季線位階等可觀察指標）；(c) 偏誤檢查：錄影時間 vs 市場開盤的時間差，提醒讀者影片觀點可能尚未反映最新數據。
- **報告總結** —— 必須是 HTML 的**最後一段**，必須實際 `Write` 進 HTML 檔案（不只放在你的回覆訊息中）。內容包含：
  - 今日整體訊號（看多／看空／中性）
  - **stance_score**（-5 ~ +5 整數）
  - **信心值**（0-10，整數或一位小數；若逐字稿不可用，信心值必須落在 0-3）
  - 3-5 條今日關鍵訊號摘要（top_signals）
  - 3-5 條主要風險（top_risks）
  - 對隔日的觀察重點

## 嚴格規則

- 寫作鐵則（faithfulness.md）優先，違反即任務失敗。
- **禁止編造因果解讀**：不要寫「推薦池鎖定」「主戰場」「代表真粉絲」「演算法開始推」這類未經證實的因果論述。
- **只引用 Eason 實際說過的話**：立場分數、目標價、產業觀點都必須能從逐字稿原話對應；不要替他腦補。
- **指標儀表板用觀察事實**：例如「費半季線 +2.3%」「MU 站上 60MA」，不要加「顯示資金回流 AI」這種因果話。
- 區分三層：**觀察到的資料**（TWSE／Yahoo 數字、Eason 逐字稿原話）／**Eason 框架對應的解讀**／**本報告自身的綜合推論**。
- 若原因不明或資料不足，明確寫「**原因不明，持續觀察**」。
- 不對未來價格做斷言；用機率、條件式語言（「若加權跌破季線且 5 日未收復 → …」）。
- HTML 要乾淨可讀（內嵌基本 CSS、表格清楚、可用顏色／emoji 標示訊號但勿過度）；不要寫 broken markup。
- **報告必須寫進 `${OUTPUT_PATH}` 這個 HTML 檔**，不可只放在你的回覆訊息中；檔案本身必須自成完整。
- 完成 `Write` 後即結束，不要做額外步驟。
