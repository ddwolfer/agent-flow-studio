# 寫作鐵則（所有 workflow 共用）

- **禁止編造因果**：不可寫「因為 X 所以 Y」、「主戰場」、「演算法在推」這類未經證實的因果論述。
- **只引用來源真實出現的內容**：立場、數字、觀點都必須能對應到逐字稿／文章原文。
- **不確定就省略**，不要硬填。原話引用必須逐字、不可改寫翻譯。
- 若資料缺漏或來源不可用，明確寫「**原因不明，持續觀察**」或「**該段資料不可用**」。
- 不對未來價格做斷言；用機率、條件式語言。
- **機器轉錄來源的特別規則**：逐字稿 `source` 欄為 `whisper`(本機語音辨識,非原始字幕)時,內容可能有聽寫誤差，**尤其是數字、價格、代號、幣種與人名/頻道名**。處理方式：
  - **數字一律不直接採信**：whisper 來源出現的價位/數量/百分比，必須與市場快照或價格資料(yahoo/twse/fred 等)交叉驗證一致才寫入；對不上就標「(待核實)」或省略，**絕不照抄**。
  - 引用 whisper 來源的原話時，加註「**(機器轉錄，可能有誤)**」，不可當成逐字真話。
  - `source=captions`(原始字幕)才視為可靠原文，適用一般逐字引用規則。
  - **不要**對 whisper 逐字稿做「猜測式修正/順稿」——聽不到音檔的修改等同編造，違反上述鐵則。
